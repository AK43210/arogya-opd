# Reporting security issues

Arogya is an early beta. Records are stored locally in the browser or Android
WebView, and exported JSON/CSV backups are unencrypted. Protect access to the
device and backup files. No patient-record cloud synchronization is implemented.

Do not publish real patient details, backups, access tokens, or sensitive
vulnerability details in a GitHub issue. Use GitHub's private vulnerability
reporting option in the repository's Security tab when available. If private
reporting is unavailable, open an issue asking the maintainer to establish a
private reporting channel, without including the vulnerability or private data.

The current beta has not undergone a comprehensive security or clinical audit.
